# Polynomial-time factorization of integer-coefficient polynomials

A personal project in algebra, algorithmics, and complexity. Enclosed is a beamer [presentation](presentation.pdf), alongside the full [mathematical description](annex.pdf) which also includes some implementation fragments in OCaml at the end of the document. Lastly, a [python implementation](factoZX.py) is included. 

To run the python program, from the shell call `Factoriser(P)` where `P` is a polynomial represented by a list (for example, `X^2+5X` is written as `[0,5,1]`). Returns a non-trivial factorization, if one exists.
